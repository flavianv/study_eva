Papa mordu

Étude mécanique d'un phénomène domestique bien connu : la fille mord le bras de son papa. On isole le bras de papa et la tête de la fille, et on modélise tout ça comme un vrai mécanisme. Colorie les classes, serre la mâchoire avec le curseur, et regarde l'Aïe-mètre.

1Classes d'équivalence Cinq classes cette fois. Et trois pièges : la montre, la barrette et le muscle.
A = { 1 } tronc de papa (bâti)
B = { 2 } bras (humérus)
C = { 3, 4, 5 } avant-bras, main, montre
D = { 6, 7, 11 } crâne, dents du haut, barrette
E = { 8, 9 } mâchoire, dents du bas

La montre est serrée au poignet et la barrette est accrochée aux cheveux : elles suivent la pièce qui les porte. Les dents du haut sont plantées dans le crâne, celles du bas dans la mâchoire, donc les deux rangées de dents ne sont pas dans la même classe : c'est justement ce qui permet de mordre.

Le muscle masséter 10 n'est dans aucune classe. Comme un ressort ou un vérin, il se déforme : on le remplace par la force qu'il exerce entre le crâne et la mâchoire.

3Graphe des liaisons Une chaîne ouverte et une boucle fermée. Où est la boucle ?

Le bras de papa est une chaîne ouverte A → B → C. La boucle fermée est C → D → E → C : l'avant-bras est coincé entre les deux mâchoires. Plus le muscle serre, plus la boucle se referme sur le bras.

4Statique : qui gagne ? On isole la mâchoire E. Quelle force arrive aux dents si le muscle tire avec Fm ?

Trois actions sur la mâchoire : le muscle (force Fm, à a = 3 cm de l'articulation J), le bras de papa sur les dents du bas (force Fd, à b = 7,5 cm de J), et le crâne sur la mâchoire (pivot en J, moment nul autour de z).

PFS, moments en J autour de z : Fm · a − Fd · b = 0, donc Fd = Fm · a / b = 0,4 · Fm.

…

La mâchoire est un levier qui perd de la force : le muscle est tout près de l'articulation et les dents sont loin. En échange, les dents bougent vite et loin quand le muscle se contracte un peu. C'est comme la pédale de commande, mais à l'envers.

Les cotes sont indicatives. Les valeurs de l'Aïe-mètre ne sont pas validées scientifiquement par papa.

5Schéma cinématique minimal Rotule, pivots, ponctuelles : dessine-le avant d'ouvrir.

La rotule de l'épaule se dessine comme une boule (B) dans une cavité (A). Le coude et la mâchoire sont des pivots. Chaque dent qui touche le bras est une ponctuelle : un point posé sur la ligne C.
