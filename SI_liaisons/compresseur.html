Compresseur à piston

Un moteur électrique fait tourner le vilebrequin. Par la bielle, le piston monte et descend dans le cylindre et comprime l'air. Colorie les pièces par classe d'équivalence, fais tourner le vilebrequin, puis vérifie. Les réponses détaillées sont en bas, masquées : réponds d'abord dans ta tête.

1Classes d'équivalence Combien de groupes de pièces sans mouvement relatif ? Lesquels ?
A = { 1, 2, 3, 4, 5 } bâti
B = { 6 } vilebrequin
C = { 7 } bielle
D = { 8, 9, 10 } piston

Le carter, le cylindre, la culasse et leurs vis sont assemblés : ils forment le bâti. Le coussinet 5 est emmanché dans le carter, il fait donc partie du bâti ; le vilebrequin tourne dedans. L'axe 8 est monté serré dans le piston et le segment 10 est logé dans sa gorge : ils bougent avec le piston. La bielle est seule : elle tourne par rapport au vilebrequin et par rapport au piston.

Piège classique : le coussinet et le segment sont en contact avec une pièce mobile, mais ce qui compte, c'est à quelle pièce ils sont fixés.

2Types de liaisons Pour chaque paire de classes en contact : quelle liaison, quel axe, combien de degrés de liberté ?
PaireLiaisonAxeMouvements permisPourquoi
A – BPivot(O, z)1 : RzLe tourillon du vilebrequin tourne dans le coussinet ; épaulements : pas de translation.
B – CPivot(P, z)1 : RzLa tête de bielle tourne autour du maneton, calée axialement.

Pourquoi pas une glissière entre A et D ? Rien dans le contact piston/cylindre n'empêche la rotation autour de y : c'est la bielle qui l'empêche, pas le cylindre. On modélise le contact tel qu'il est.

3Graphe des liaisons Dessine les 4 classes et relie celles qui se touchent. Le graphe est-il ouvert ou fermé ?

Une seule boucle fermée : A → B → C → D → A. Chaque classe est reliée à deux autres. C'est ce qui permet de transformer la rotation du vilebrequin en translation du piston.

4Schéma cinématique minimal Place les symboles normalisés dans le plan (x, y). Il bouge avec le curseur du vilebrequin.

C'est le système bielle-manivelle. Le pivot en O est accroché au bâti (triangle hachuré). Les pivots en P et Q sont de simples cercles entre deux barres. Le piston est un bloc qui coulisse entre deux traits du bâti. Le schéma est minimal : une liaison par paire de classes en contact, donc 4 liaisons pour 4 classes.

En vue plane, on dessine souvent le pivot glissant A–D comme une glissière, car la rotation autour de y ne se voit pas dans le plan (x, y).
