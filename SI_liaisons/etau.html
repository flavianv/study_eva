1Classes d'équivalence Combien de classes ? Attention au levier : bouge-t-il par rapport à la vis ?
A = { 1, 2, 3, 10 } bâti
B = { 5, 8, 9 } vis de manœuvre
C = { 4, 11 } mors mobile
D = { 6, 7 } levier

L'écrou 2 est vissé au corps par la vis 3 : il fait partie du bâti, comme la plaquette du mors fixe. La bague 8 est goupillée (9) sur la vis : elle tourne avec elle. La plaquette 11 est fixée au mors mobile. Le levier forme une classe à lui seul avec ses embouts, car il peut coulisser et tourner dans la tête de vis.

Beaucoup d'élèves mettent le levier avec la vis. Fais bouger le curseur « Levier » : il glisse par rapport à la vis, donc ce n'est pas la même classe.

3Graphe des liaisons Y a-t-il une boucle ? Une branche ouverte ?

Une boucle fermée A → B → C → A (celle qui fait avancer le mors), plus une branche ouverte B → D. Le levier ne sert qu'à tourner la vis à la main.

C'est la même boucle que dans le casse-écrou : hélicoïdale, pivot, glissière. Le casse-écrou est en fait un petit étau.

4Schéma cinématique minimal Dessine-le avant d'ouvrir. Il bouge avec les deux curseurs.

Symboles utilisés : hélicoïdale (rectangle avec hélice), pivot (rectangle et deux traits sur l'arbre), glissière (rectangle autour d'une barre rectangulaire), pivot glissant (rectangle autour d'un arbre, sans les deux traits : l'arbre peut coulisser). Le mors fixe fait partie du bâti.
